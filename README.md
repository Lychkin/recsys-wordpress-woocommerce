# Рекомендательная система для e-commerce на WordPress и WooCommerce

## Описание проекта

Этот проект реализует **персонализированную рекомендательную систему** для интернет-магазина мебели на платформе **WordPress + WooCommerce**.

Система использует:

- историю покупок,
- просмотры товаров,
- добавления в корзину

для обучения **модели коллаборативной фильтрации**, которая рекомендует пользователям релевантные товары и похожие позиции.

Модель написана на **Python** и интегрируется в WordPress через **FastAPI**.

---

## Идея рекомендательной системы

Вместо явных оценок, используется **Implicit Feedback** — неявные сигналы интереса пользователя:

| Событие       | Смысл                        | Вес |
| ------------- | ---------------------------- | --- |
| `view`        | Пользователь посмотрел товар | 1   |
| `add_to_cart` | Проявил сильный интерес      | 3   |
| `purchase`    | Купил товар                  | 5   |

Эти сигналы агрегируются в **матрицу взаимодействий User × Item**, которая подаётся в модель.

---

## Используемый алгоритм

### Alternating Least Squares (ALS) for Implicit Feedback

Используется библиотека `implicit` (стандарт в e-commerce).

ALS:

- факторизует матрицу `User × Item`
- обучает латентные вектора пользователей и товаров
- позволяет находить:

  - персональные рекомендации
  - похожие товары

Это тот же класс алгоритмов, что используется в Amazon, Netflix, Spotify.

## Описание ключевых файлов

### `fetch.py`

ETL-скрипт (Extract → Transform → Load), который:

1. Загружает покупки (`purchase`) из WooCommerce REST API
2. Загружает поведенческие события (`view`, `add_to_cart`) из отдельного API
3. Объединянет эти события в одну структуру
4. Создаёт файл `raw_events.csv`

---

### `prepare_data.py`

ETL-скрипт (Extract → Transform → Load), который:

1. Агрегирует все взаимодействия, суммируя их веса
2. Назначает веса событиям
3. Удаляет лишние колонки
4. Создаёт файл `popular_items.csv`
5. Создаёт файл `events.csv`

---

### `train_als.py`

1. Читает `events.csv`
2. Строит разреженную матрицу `users × items`
3. Обучает ALS-модель
4. Сохраняет `als_model.pkl`

Модель умеет:

- рекомендовать товары пользователю
- находить похожие товары

---

### `app.py`

FastAPI сервер, который:

- загружает модель
- отдаёт рекомендации

API:

| Endpoint                    | Назначение                |
| --------------------------- | ------------------------- |
| `/recommend/user/{user_id}` | персональные рекомендации |
| `/recommend/item/{item_id}` | похожие товары            |

Пример ответа:

```json
[
  { "item_id": "55", "score": 2.91 },
  { "item_id": "14", "score": 2.12 }
]
```

## Почему используется Implicit Feedback

В e-commerce:

- люди редко ставят оценки
- но много кликают, смотрят и кладут в корзину

Поэтому модель обучается на:

> «что пользователь делал», а не «что он сказал»

Это позволяет:

- рекомендовать даже без покупок
- работать с холодным стартом
- учитывать реальное поведение

## Как запустить

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Собрать данные:

```bash
python fetch.py
```

3. Подготовить датасет:

```bash
python prepare_data.py
```

4. Обучить модель:

```bash
python train_als.py
```

5. Запустить API:

```bash
py app.py
```
